## 🎁 What's Included in the Suite?

By installing **F5 Anything Suite**, you get the complete zero-config development environment powered by 3 complementary tools designed to help Computer Science learners focus on code instead of tool configuration:

1. ⚡ **[F5 Anything](https://github.com/loerei/f5-anything)**: Press `F5` to build & run any code file (C, C++, Python, Java, Go, Rust, TS, C#, Bat) instantly.
2. 🧹 **[No More .vscode](https://github.com/loerei/no-more-vscode)**: Redirect all compiled binaries to `C:\VscodeBuilds` to keep your project workspace 100% clean.
3. 🛠️ **[Easy Binary](https://github.com/loerei/easy-binary)**: Auto-detects and installs missing compilers (MinGW GCC, Python, JDK, Go) via Winget.

---

## 🚀 Quick Start

1. Click **Install** on this extension pack.
2. Open any source code file (`.cpp`, `.py`, `.java`, `.bat`, etc.).
3. Press **F5** to run!
